# 原论文 PDF

由于 GitHub 文件接口对单次二进制传输有限制，原始论文 `D01.pdf` 以无损分片形式保存在 `parts/` 目录中。分片按原始字节顺序拼接后，可恢复与参赛论文完全相同的 32 页 PDF。

## 一键还原

在仓库根目录运行：

```bash
python paper/restore_pdf.py
```

还原文件将生成于：

```text
paper/D01.pdf
```

脚本会自动执行 SHA-256 校验。正确校验值为：

```text
4e31a7907dc46e4328589e90500e179561fcb7d20aca3c708cb5115026f478d6
```

原始文件信息：

- 页数：32 页
- 页面：A4
- 文件大小：2,743,439 字节
- 加密：否
